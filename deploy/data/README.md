# 外部工具导入

`external-tools-20261028.sql` 是 2026-10-28 从本机 PostgreSQL `tool` 表导出的 73 条 `source_type = 'external'` 记录，不是源码内置的 160 条清单。SQL 已包含全部导入数据，不需要另外携带 JSON 或安装 Node.js 依赖。

在内网数据库服务器或装有 PostgreSQL 客户端的电脑执行（替换连接参数，密码由客户端提示输入）：

```sh
psql -X -h <数据库地址> -p 5432 -U <数据库用户> -d <数据库名> -W -v ON_ERROR_STOP=1 -f external-tools-20261028.sql
```

也可以用 Navicat 连接目标库后执行整个 SQL 文件。目标需要已部署本项目的 `public.tool` 表结构；执行账号需要该表读写权限以及 public schema 建表权限。

- 相同 ID 更新内容，不存在的 ID 新增；不删除内网独有的工具。
- 保留已有记录的自增主键、创建时间和 invokes 使用次数；新增记录的 invokes 为默认值 0。
- 内部工具不修改；若 ID 与非外部工具冲突，整批报错回滚。
