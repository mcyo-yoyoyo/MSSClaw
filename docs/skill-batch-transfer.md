# Skill 批量导入导出

在后台「配置Skill」点击「导出全部清单」，下载当前账号可见的 Skill 明细及资源包。ZIP 根目录中的 `Skill明细表.xlsx` 可直接用于批量导入。「技能明细」的 35 列按《skill明细表-模板(1).xls》第一张表第 5 行的顺序排列。该模板第二张表记录的是旧列名。

各 Skill 的资源包按「Skill 名称.zip」命名。已上传文件包的条目导出原包，无上传包的条目按平台已有内容生成。文件名中的非法字符用下划线替代，重名包用不同目录区分。

## 按名称导入

1. 点击「批量导入」，选择单个 `.xls` 或 `.xlsx`。可使用导出的工作簿，或在提供的模板中填写数据。
2. 预览中逐行检查名称和处理方式，展开更新行可对照各字段的原值和新值。匹配依据是 Skill 展示名称。新名称生成新草稿；修改名称会新增一条，原名称保留。表内重名或目录内多个同名条目会提示错误。
3. 点击「确认导入」。新增时服务端再次检查重名。更新只发送变更字段和预览时的时间戳。空单元格保留旧值，未出现在表格中的 Skill 保留。失败项可重试；目录发生并发修改时重新选表比对。

可维护来源、创建者、领域、区域、业务场景、英文名称、调用指令、可见范围、是否可调用、是否精选推荐、运营标签、搜索关键词及使用须知。新建行使用平台生成的 ID。“是否精选推荐”留空时，新草稿默认为“否”。填写“是”时保存为精选。现有 Skill 保留原 ID 和发布状态。正文、文件包、版本归档和附件请在单个 Skill 中维护。

Excel 的「来源」列和后台「配置Skill → 编辑 → 身份信息 → Skill 来源」维护同一项可选分类。公司内创建的 Skill 选「内部」，从公司外引入的选「外部」。后台编辑可清空已有分类。用 Excel 新建时可留空来源，更新时空单元格保留原值。

Skill Hub 默认显示全部来源和场景，包含未选来源的 Skill。点左侧「内部」或「外部」按来源筛选，再点已选项恢复全部来源。右侧的业务场景也可点选或取消，两级筛选可组合。

在单条草稿中维护文件包后，点击「提交审批」。编辑器会先保存 Skill，再等待审批单写入。若出现「重试审批」，文件包与版本已经保存，点击该按钮可继续提交同一份审批。

SkillID、时间、更新者、版本历史、执行正文标记、计数、投票人和预留列用于导出展示。修改这些单元格不会覆盖系统记录。后台保存更新时记录操作者与时间。预留字段留空。近 30 天下载总量按平台统计日期计算，含当天。投票人列展示系统记录的姓名；成员库没有独立工号字段。
