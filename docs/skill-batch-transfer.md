# Skill 批量导入导出

后台 Skill 管理操作区按“搜索、导出全部清单、批量导入、提报 Skill”排列。“导出所选”入口及勾选控件已移除；“导出全部清单”仍是运营统计 Excel。迁移 ZIP 的打包函数保留，当前页面不提供其导出入口。

迁移 ZIP 的根目录只有两项：

```
skills.xlsx
skills/
  <Skill ID>/
    SKILL.md
    scripts/...
    references/...
    assets/...
```

Excel 的工作表名为 `Skills`，格式版本为 `1`。每行对应一个 Skill，目录路径必须为 `skills/<Skill ID>/`。ID 允许字母、数字、下划线和连字符，最长 128 字符。

表格包含 ID、目录、名称、版本、描述、调用命令、应用领域与区域的编码及名称、可见性、分类、作者、连接器、图标、标签及其他配置 JSON。以编码确定领域和区域，名称列仅用于阅读；空区域表示不限。可见性使用 public/org/private，org 必须填写领域。其他配置包括英文名称和描述、业务场景、执行步骤、检索词、使用须知、文本案例和环境说明。Excel 单元格最多 32767 字符，超出会明确阻止导出。

导出有原始包的 Skill 时保留包内全部文件，包括二进制资源；去除所有文件共有的外层目录。没有原始包时根据平台正文生成 SKILL.md，并在文件来源列注明。原始包不可读或缺少唯一根 SKILL.md 时阻止导出，不静默退化成正文包。SKILL.md 是导入正文来源，Excel 是管理信息来源。

独立上传到平台的案例附件、自定义头像以及评测/审批/调用记录不属于技能目录，此版本不随迁移包导出；技能目录本身携带的附件则完整保留。更新已有 Skill 时保留未涉及的现有配置。

导入先解析预览，再确认保存。重复 ID 默认跳过；勾选覆盖后更新已有条目，保持其发布状态和调用统计。新增条目为草稿且不可调用，后续通过现有编辑/审批流程发布。未知分类、重复 ID、缺少文件会指出 Excel 行及原因。服务端仍校验目录写入和技能包上传权限，非管理员沿用编辑页的组织范围约束。

每批最多 100 个 Skill、压缩包 200 MiB；沿用 ZIP 安全检查，包括最多 2000 个文件、解压总量 512 MiB、路径及压缩率检查。超过限制请分批。处理在当前页面逐项执行，压缩和解压使用异步接口；页面显示进度、成功、跳过、失败结果，允许重试未成功条目。不是服务器后台任务，刷新或关闭页面会丢失当前处理进度。

保存逐条等待服务端确认，失败时不更新本地列表；覆盖使用原 updatedAt 进行冲突检查。网络中断无法确定服务端是否已提交时保留上传文件，避免误删已引用文件；可能遗留未被引用的包，需要对象存储日常清理处理。重试前刷新目录可确认实际写入结果。
