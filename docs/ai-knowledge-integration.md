# 智库原生界面融合

本次按已确认的右下角 Voxel Bot 与独立对话稿实施。入口统一至机器人，原业务页面的输入框继续支持本页搜索，不再承担智库跳转。

## 页面与能力

- 平台公共布局挂载 KnowledgeDock，业务页面显示；智库页与运营视角不重复显示。
- `#/ai-knowledge` 使用 KnowledgeChatPage：找方案、洞察、平台介绍，新建/恢复会话、历史记录、来源抽屉、确认需求和生成方案。
- 找方案与洞察继续使用现有自有编排，不引入 Agent 框架。平台介绍依据内置功能说明回答并记录会话。
- 方案详情继续使用 LegacyAiKnowledgePage。原有我的方案、后台方案表、能力详情、Word 导出和打印/PDF 保留；新方案额外呈现完整实施步骤及人工检查点。
- Voxel Bot 本地素材位于 `apps/web/public/knowledge/voxel-bot.svg`，DiceBear / CC0；不依赖运行时外部素材请求。

## 数据兼容

| 记录 | 读取与延续方式 |
| --- | --- |
| 新会话与试验版会话 | 按 actor 命名空间读取 appSetting；服务端保留 revision 并发校验 |
| 旧 aiKnowledgeDraft | 所有者历史列表可见；选择后复制对话和需求到新会话，保留原行 |
| 旧 aiKnowledgeSolution | 从原方案接口读取详情；继续对话时复制 messages 和 demand，原方案保留 |
| 新方案 | 事务写入 aiKnowledgeSolution 和新会话；content 包含旧格式字段及 pilotPlan/sourceSessionId |
| 早期浏览器本地方案 | 访客历史区可见，并可通过校验后的 import-local 接口复制为新会话 |
| 试验页独立访客记录 | 本浏览器存在 mss-pilot-visitor 时提供导入按钮；显式导入到当前身份，保留来源记录，按当前身份生成独立ID，重复导入不覆盖已有会话 |

历史列表每页50条，可加载更早记录。账户切换会清空当前展示并按新身份重载；不将不同账户的会话自动合并。导入是复制，不删除旧数据。

- 本次只执行构建，没有执行自动化测试或浏览器业务验收。构建结果不代表用户流程已验收。

## 平台介绍动效

- 点位：出发 → 首页导航 → 智库入口 → AI快讯 → 案例洞察价值 → 案例阅读方法 → 外部搜索 → 工具卡片 → 内部办公 → Skill/Agent 切换 → 能力卡片 → 结束。
- 用户点击下一步才导航。路由加载与锚点就绪后先滚动到目标，机器人约680ms移动，约720ms后展开文案。
- 不点击工具、提交按钮或案例；只切换介绍所需的页面及快讯/案例页签。用户自行打开详情或其他页面时暂停。
- 锚点暂未出现时最多等待约6秒，然后在安全位置介绍并明确提示暂无可展示区域；不伪造案例或资产。
- 当前点位仅保存在本浏览器 localStorage，退出后可继续或重头开始。结束操作清除进度。
- 监听滚动与窗口尺寸，重新定位高亮；窄屏收窄气泡。系统减少动态效果时取消过渡与轻跳。
- 本次运行前端构建；未运行自动化测试或浏览器验收，实际遮挡及页面点位效果待人工验收。

## 独立方案文档

- 新方案仍使用有所有者权限的 aiKnowledgeSolution 表作为保存索引，但正文改存 content.document（schemaVersion=1），不再组装旧版 demand/diagnosis/toolRecommendations。
- 文档包含需求摘要、概述、步骤、交付物、限制、来源和 sourceSessionId；关联对话继续保存在原会话中。
- 确认生成后打开 SolutionDocumentReader；返回对话仅展示标题、摘要和查看按钮。我的方案与历史方案入口使用同一阅读器。
- 旧试验版 pilotPlan 在读取时转成新阅读格式，不写回原数据；更早的旧方案仍使用原详情。
- Word 与打印/PDF 导出按独立文档章节输出。未运行自动化测试或浏览器验收。

## MAX 对话反馈（2026-10-31）

- 发送后立即清空输入框，在对话区显示本次问题；首轮发送即进入连续对话布局，输入框固定在底部。
- 等待回答时显示“MAX 正在回复”和三点动效；确认生成方案时改为“MAX 正在生成方案”。系统减少动态效果时不播放动效。
- 成功后用接口返回的已保存消息替换临时问题和等待状态；历史列表在后台刷新，不延长回复中的状态。方案成功后仍打开独立方案文档。
- 回复失败时在当前问题下方提示错误并提供重新发送，重试复用当前问题气泡，不重复追加；仅临时显示的失败问题不写入历史记录。返回 MAX 首页或切换账户后清空临时状态，并忽略旧请求的界面更新。
- 问题轮播仅用于 MAX 空白首页，连续对话、输入聚焦或请求处理中不显示。
- 仅运行前端构建；未运行自动化测试或浏览器验收。
