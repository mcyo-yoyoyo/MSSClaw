# MAX 每日问题提示

## 行为

找方案与洞察各6条问题。仅在 MAX 空白首页、输入为空且未聚焦时5秒轮播，点击只填入输入框并聚焦，不自动发送。输入框聚焦、发送处理中或已进入连续对话时隐藏提示，清空后仍聚焦也不重新显示。悬停、键盘焦点、后台标签页或系统减少动态效果时停止自动轮换。

## 生成与数据

- 后端 AiKnowledgeSuggestionsService 每天北京时间09:00更新，启动时补齐当前更新周期。
- 找方案读取公开且已发布的 Skill、Agent、工具；洞察读取最新快讯与已发布案例。共享缓存不包含组织内或私有资产。
- 真实模型生成用户口吻的问题，要求恰好6条、不重复、每条关联真实候选sourceIds。校验失败再修正一次。
- 缓存存于 appSetting 的 max-suggestions:v1:solution / insight；带生成时间、更新周期、模型和来源ID。
- 请求立即返回缓存，后台刷新，不等待模型。没有缓存时前端保留原提示，稍后轮询；失败保留上一批有效数据，5分钟内不重复模型请求。
- 返回前重新核对当前公开资料，已删除或不可见的来源不继续展示，触发后台重建。

## 运行

依赖服务持续运行。服务未运行时不执行定时任务，下次启动补齐。新模块增加了后台模型调用，日常每个模式一批；不按访客访问次数重复生成。

## 交付边界

运行前后端构建，未运行自动化测试或浏览器验收。首批真实生成结果需从启动日志与缓存确认。
