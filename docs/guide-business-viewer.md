# MSS AI 提效作战平台 · 快速上手与使用说明

**适用角色：业务用户、只读访客**

> 本文按「体验主线」说明：从登录进入 → 逛工具与集市 → 学用 Skill/Agent → 看 AI 快讯 →（业务用户）做任务与提报。  
> 只读访客与业务用户看到的货架与快讯基本相同；差异在文末「角色对照」。

---

## 一、平台能帮你做什么

面向一线业务与访客的核心价值是 **学工具、用工具、找样板**，不必先理解后台配置：

| 你想做的事 | 去哪里 |
|------------|--------|
| 找外部 AI / SaaS 工具 | 顶栏 **外部工具精选** |
| 找公司内可直接用的办公工具 | 顶栏 **公司工具推荐** |
| 找公司沉淀的 Skill / Agent / 案例 | 顶栏 **MSS工具集市** |
| 看每日 AI 产业动态 | 顶栏 **AI快讯** |
| 回首页总览、进场景通道 | 顶栏 / 侧栏 **首页** |
| 看历史任务与协作（业务用户） | 侧栏 **任务记录** / **协作空间** |
| 看系统通知 | 顶栏铃铛 **我的消息** |

产品名：**MSS AI提效作战平台**。

---

## 二、体验主线（推荐路径）

```text
登录进入工作台
    ↓
首页：看通道与动态，建立「学 / 用 / 造」心智
    ↓
逛三货架（外精选 → 公司推荐 → MSS集市）——先浏览、再打开/下载
    ↓
（可选）AI快讯：速读 + 下载 HTML 转发同事
    ↓
（业务用户）从集市或首页进入做任务 / 打样；需要时提报工具或 Skill
```

访客止于「浏览 + 下载学习」；业务用户可继续「执行 / 提报」。

---

## 三、登录与进入

1. 打开平台地址，进入登录页（「使用组织账号进入工作台」）。
2. 输入组织账号邮箱与密码 → **进入工作台**。
3. 体验环境若提示初始密码，以登录页说明为准；正式环境请使用组织下发的密码。

进入后默认在 **业务工作台**：顶栏货架 + 侧栏工作平台入口。

---

## 四、首页：从总览开始

**首页**是体验起点，通常包含：

- 平台口号与通道入口（通往外精选 / 公司推荐 / MSS集市）。
- 站内动态条（如 AI快讯摘要、培训/上线类公告）——点进可跳转对应页。
- 场景或能力露出（如已精选的场景技能 / 专家，视当前方案开关而定）。

**建议操作：** 先点顶栏三个货架各逛一遍，再回到首页用「最近使用」或场景入口做二次到达。

可用左侧 **领域 / 区域** 作浏览筛选（当前阶段主要用于缩小列表，帮助你按业务视角找东西）。

## 五、三货架使用流程

### 5.1 外部工具精选

**用途：** 从工作场景出发，浏览外部 / 国内精选 AI 工具。

**流程：**

1. 顶栏进入 **外部工具精选**。
2. 用场景 / 类型等筛选缩小范围。
3. 打开工具卡片 → 访问官网或查看 **How to**（若有）。
4. 使用时注意：外部服务为第三方，**勿输入涉密或未授权数据**，遵守公司规定。

**业务用户：** 可使用 **提报工具**，把值得上架的外部工具提交给运营审核。  
**只读访客：** 仅浏览与打开，无提报。

### 5.2 公司工具推荐

**用途：** 不必先学复杂工具，从「记、读、写、问」等日常办公动作进入公司统一入口。

**流程：**

1. 顶栏进入 **公司工具推荐**。
2. 按办公场景网格选择（如记录、阅读、写作、问答等）。
3. 在授权范围内打开工具体验（链接与标识来自平台已配置的公司工具）。

**业务用户** 同样可提报；**访客** 只读。

### 5.3 MSS工具集市

**用途：** 公司内部建设的能力货架——按 **业务场景** 找 Skill、Agent 与案例。

**流程：**

1. 顶栏进入 **MSS工具集市**。
2. 选择业务场景分类（与业务视角对齐的场景篮子）。
3. 在场景下切换：
   - **Skill Hub**：快速上手说明 → **下载技能包**；（若方案开放）可 **去执行**。
   - **Agent Hub**：学习说明 → **下载学习包**；可执行时 **去打样**。
   - **案例**：查看样板文档 / 材料。
4. 需要沉淀贡献时（业务用户）：**提报 Skill** / **提报案例**。

**下载建议：** 先下载到本地学习结构与指令，再在有权限时于任务中调用。

## 六、AI快讯

**用途：** 每日 AI 产业动态精选速读；便于转发同事。

**流程：**

1. 顶栏进入 **AI快讯**。
2. 左侧按日浏览，右侧阅读标题与摘要；点标题可打开原文。
3. 需要转发时点 **下载**，得到 HTML；用 Outlook / 企业邮箱打开后人工发送。  
   - 邮件「订阅」、WeLink 推送当前为待开通（按钮置灰），不影响下载使用。

## 七、做任务与消息（业务用户主路径）

### 7.1 从货架到任务

当方案开放执行能力时，常见路径为：

1. 在 MSS集市或首页点到可执行的 Skill / Agent。
2. 进入任务对话区：按页面提示发送演示任务或输入指令（如 `/技能指令`）。
3. 查看结果；需要时从 **任务记录** 回看历史。

**只读访客** 不能发起执行；页面会提示当前为只读。

### 7.2 任务记录与协作空间

- **任务记录**：进度、结果、历史会话（视展示方案开启）。
- **协作空间**：多人协作会话入口（完整方案下业务可开；访客通常不可用）。

### 7.3 我的消息

顶栏铃铛进入 **我的消息**：系统通知与协作消息。  
每日产业动态请看 **AI快讯**，不要与消息列表混淆。

## 十、使用小贴士

1. **先逛后用：** 外精选摸边界 → 公司推荐解决日常 → 集市拿公司沉淀能力。  
2. **场景优先：** 在 MSS集市先选业务场景，再找 Skill/Agent，比盲搜更贴近业务语言。  
3. **下载不等于已上架可调用：** 学习包可先学；对话执行需资产为可调用状态并由有权限角色发起。  
4. **共享环境：** 部门体验机若提示「共享服务未连通」，你可能暂时看不到同事刚上传的内容——请联系运维检查后再试。  
5. **安全：** 外链工具与 AI 对话均勿粘贴涉密信息。
