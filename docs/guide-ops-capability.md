# MSS AI 提效作战平台 · 快速上手与使用说明

**适用角色：平台运营、能力开发**

> 本文按「运营 / 建设主线」说明：登录进入运营台 → 配置并上架能力 → 维护货架与站点触达 → 组织与展示治理。  
> 能力开发侧重 **配置 Skill（及方案开放后的 Agent/工具）**；平台运营额外负责门户、组织、展示与租户。

---

## 一、你们负责什么

| 角色 | 工作台 | 核心职责 |
|------|--------|----------|
| **平台运营** | 平台运营台 | 能力全量配置 + 门户运营 + 组织权限 + 展示配置 + 租户配置；保障全员能逛、能下、能用 |
| **能力开发** | 平台运营台 | 创建与维护 Skill（MVP 默认）；标准/完整方案下可开 Agent、工具等；不负责门户/组织/展示等治理项 |

角色由账号绑定，**不能**在界面上切换业务壳 / 运营壳。

阶段 1 成功标准（请对照验收）：

1. 同事能登录并逛通三货架与 AI快讯。  
2. 你们上传的 Skill / Agent / 工具，**其他电脑刷新后能看到并可下载**。  
3. 外精选与公司工具可维护、可打开。

---

## 二、体验主线（推荐路径）

```text
登录 → 进入平台运营台
    ↓
确认共享服务已连通（顶栏提示 / 保存后是否「仅存本机」）
    ↓
配置 Skill（上传 → 业务场景与归属 → 发布/上架审批）
    ↓
（平台运营 / 方案开放后）配置 Agent、配置工具，挂到集市与公司场景
    ↓
门户运营：货架精选、How to、公告、AI快讯邮件文案
    ↓
组织权限（账号角色）+ 展示配置（谁看见哪些入口）
    ↓
用业务用户账号抽检：上传 → 可见 → 下载 / 打开
```

---

## 三、登录与工作台结构

1. 使用运营或能力开发账号登录。  
2. 进入后为 **平台运营台**：侧栏分 **工作平台 / 能力配置 / 系统设置**；顶栏有 **管理后台** 下拉。  
3. 体验环境初始密码若为演示口令，请在 **组织权限** 中尽快改密或关闭演示策略。

### 侧栏与管理后台常见入口

| 入口 | 谁用 | 做什么 |
|------|------|--------|
| **配置Skill** | 运营 + 能力开发 | 技能包主数据、业务场景、可见性、上架可调用 |
| **配置Agent** | 多为平台运营（展示方案可开给能力开发） | 编排 Skill、场景归类、调用/导出专家包 |
| **配置工具** | 多为平台运营 | 外精选 / 公司工具主数据与链接 |
| **门户运营** | 仅平台运营 | 场景内容、货架运营、How to、公告、快讯邮件文案等 |
| **组织权限** | 仅平台运营 | 成员、角色、部门区域字典、审计 |
| **展示配置** | 仅平台运营 | 按角色开关侧栏入口 |
| **租户配置** | 仅平台运营 | 数据空间启停与顶栏租户 |

MVP 演示方案下：能力开发默认主要看到 **配置Skill**；平台运营通常含 Skill / Agent / 工具 + 治理项。

## 四、上线前必做：共享同步

部门机多用户共享依赖 **Nginx 反代 `/api` + Nest 后台**。

- 健康检查：`/api/v1/health` 应返回 JSON。  
- 保存 Skill/Agent/工具后：Toast 应出现「已排队同步到共享服务」。  
- 若出现「仅存本机」或顶栏橙/红条：内容可能只有你本机有，**先修 API 再开放体验**。  
- 双机验收：电脑 A 新建并保存 → 电脑 B 刷新可见并可下载。

详见 `deploy/LAN-PRODUCTION.md`。

## 五、配置 Skill（能力建设主流程）

这是能力开发的日常主线，也是运营保证「集市有货」的基础。

### 5.1 流程总览

```text
进入「配置Skill」
  → 创建（上传 .skill.zip / SKILL.md / JSON，或空白创建）
  → 填写名称、正文、指令
  → 第 2 步：选择「业务场景分类」+ 所属职能/区域 + 可见范围
  → 第 3 步：是否申请上架可调用；可选精选露出到「MSS工具集市 · 场景技能」
  → 保存（可能进入审批）
  → 列表中下载包 / 调用验证
```

### 5.2 关键与编辑要点

1. **上传包：** 支持标准 Skill 包解析；确认中文名、描述、指令（如 `/xxx`）。  
2. **业务场景分类（必选）：** 与业务用户在 MSS集市看到的场景对齐；决定场景归类与筛选。  
3. **所属职能（单选）/ 区域：** 用于归属与列表展示；能力开发界面可能提示「仅能归属本人组织」——以当前可选范围为准。  
4. **可见范围：** **公开可见** / **组织内**（默认公开可见）。  
   - 阶段 1 短期：组织数据权限开关关闭时，「组织内」与公开在浏览上效果接近，仍建议按真实意图勾选，便于阶段 2 打开隔离。  
5. **申请上架可调用：** 勾选后走审批（提交人 → 业务主管 → MSS 质量与运营）。未上架则沉淀在目录，业务侧执行可能受限。  
6. **精选露出：** 勾选后按第 2 步所选业务场景进入集市「场景技能」露出。

### 5.3 列表日常操作

- 筛选：职能、区域、**业务场景**、范围。  
- **调用：** 需为可调用状态。  
- **下载 / 导出全部：** 便于分发与备份。  
- **配置：** 回到编辑向导。

## 六、配置 Agent（编排与专家包）

### 6.1 流程总览

```text
进入「配置Agent」
  → 新建或编辑
  → 填写名称、Persona、演示任务、编排计划
  → 选择「业务场景分类」（替换原任务类型 / 提效维度心智）
  → 挂载「配置Skill」目录中的 Skill（可搜索；建议指定主 Skill）
  → 发布状态与可见范围；可选精选到「做任务 · 场景专家」
  → 保存（可能审批）→ 调用验证 / 下载 .agent.zip
```

### 6.2 要点

- **业务场景分类：** 与集市业务用户视角一致；决定场景专家归类。  
- **挂载 Skill：** 实时读取配置 Skill 目录；主 Skill 影响默认指令。可跳转去配置 Skill。  
- **调用：** 发送演示任务并注入 Persona / Skill。  
- **下载包：** 导出专家包供学习或迁移。

---

## 七、配置工具（外精选 + 公司工具）

### 7.1 流程总览

```text
进入「配置工具」
  → 新建工具：名称、描述、类型（外部 / 公司等）、访问链接、Logo
  → 挂业务场景 / 货架槽位（外精选或公司办公场景）
  → 发布与可见性 → 保存（可能审批）
  → 业务侧在「外部工具精选」「公司工具推荐」抽检打开
```

### 7.2 要点

- **外部工具：** 必须填写可访问链接；卡片提示安全使用规范。  
- **公司工具：** 链接与 Logo 会直接影响公司推荐页体验，变更后请双机刷新确认。  
- 工具主数据在 **配置工具**；门户里的 How to / 精选运营在 **门户运营**，两边配合。

## 八、门户运营（仅平台运营）

进入 **门户运营**，按分组理解：

| 分组 | 典型能力 |
|------|----------|
| 场景 | 场景内容、场景分类 |
| 货架 | 外精选上架/置顶、公司办公场景、外精选分类、How to |
| 站点 | 站内公告、AI新闻（站内稿）、**AI快讯邮件**文案、建设口径 |

**与顶栏「AI快讯」的关系：**

- 顶栏 AI快讯正文来自产业日报源 / 本地兜底，**不是**门户「AI新闻」列表。  
- **AI快讯邮件**：只配置下载 HTML 的品牌标题、引导句、按钮与落地链接，便于对外统一口径。

**操作建议：** 先配好工具与 Skill 主数据 → 再在门户做精选露出与 How to → 最后改邮件壳文案。

## 九、组织权限与展示配置（仅平台运营）

### 9.1 组织权限

- 维护成员账号、角色（平台运营 / 能力开发 / 业务用户 / 只读访客）。  
- 部门与区域字典（供筛选与归属标签）。  
- 账号设密、关闭演示口令策略（体验结束后务必处理）。  
- 审计浏览（若开启）。

阶段 1：**不做**严格组织数据隔离；领域/区域以筛选与归属展示为主。

### 9.2 展示配置

- 按角色勾选侧栏可见入口。  
- 业务用户 / 访客只应看到工作平台相关项；勿把能力配置误开给访客。  
- 能力开发的「配置 Agent / 工具」是否出现，由此与方案预设共同决定。

### 9.3 租户配置

- 控制数据空间启停与顶栏租户列表；多租户试点时再用。

## 十、发布与审批心智

```text
草稿 / 已沉淀
    → 申请上架 / 发布
    → 审批（若启用）
    → 可调用 / 已发布
    → 业务侧：集市可见、可下载；（有权限时）可执行
```

保存后请关注：

1. Toast 是否提示已同步共享服务。  
2. 用 **业务用户** 账号登录另一浏览器或电脑，确认可见与下载。  
3. 若走了审批，未通过前业务侧可能仍不可调用——需有人在审批流中处理。

## 十二、日常运维检查清单

1. `/api/v1/health` 正常；保存无「仅存本机」。  
2. 本周新增 Skill 均已选 **业务场景**，并在集市对应场景下可筛到。  
3. 外精选与公司工具链接抽检可打开；涉密提示仍在。  
4. AI快讯可打开；需要转发时下载 HTML 可用。  
5. 体验账号角色正确；演示口令策略按安全要求处理。  
6. 用业务用户走一遍：逛货架 → 下载 →（如开放）执行。
