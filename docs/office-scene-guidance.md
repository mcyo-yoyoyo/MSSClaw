# 工具与场景使用指导

工具详情页按两个独立的配置显示指导按钮。各按钮在新标签页打开自己的链接。两处都填写时同时显示，两处都留空时都隐藏。

| 详情页按钮 | 后台配置位置 | 显示条件 |
| --- | --- | --- |
| 工具使用指导 | 配置工具 → 编辑工具 → 帮助文档 URL | 工具已配置帮助文档地址 `docsUrl`。 |
| 场景使用指导 | 配置办公场景 → 编辑场景 → 场景使用指导 | 详情地址携带 `sceneId`，该场景可见、仍绑定此工具，且已配置有效的 `guideUrl`。 |

从办公场景进入工具详情时，详情地址携带场景标识。分享该详情会保留场景标识。直接打开不含场景标识的详情，只按工具配置展示「工具使用指导」。

场景指导支持内网或公网 HTTP/HTTPS 地址，最多 2048 字符，不接受带用户名或密码的 URL。

数据存储在 `office_scene.guide_url`。部署时执行项目现有 Prisma migration deploy 流程，并重新生成 Prisma Client、构建并重启 API。迁移 `20261111030000_office_scene_guide_url` 只新增可空字段，旧场景不需补数据。
