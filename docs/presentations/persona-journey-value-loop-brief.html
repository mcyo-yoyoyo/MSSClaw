导如何讲述用户之旅主线（看岗位故事前先对齐）

1. 先回答你的疑问：主线到底是哪一条？

口径 本质 讲述地位
学习 → 准备 → 开干 → 沉淀 用户价值主线（为什么按这个顺序用） 唯一主线 · 对外口播只用这条
逛·发现与开工 / 做·计划与交付 / 交·预览与推送 / 学·复制与沉淀 界面动线拆解（手指点哪里） 字幕级对照，嵌在主线下，不并列开讲
用 / 得 / 留 / 回 组织复利的解释草稿 废弃并列：收进「沉淀带走什么」一句话
裁决：体验之旅主线 = 学习 →（准备）→ 开干 → 沉淀。 括号表示：准备是真环节，但讲述权重随版本变化——不是另立一套「逛做交学」来取代它。

2. 「准备」会不会在 2.0 没体感？——会变薄，不删主线

1.0 · 准备要实讲

体外参照清单：硬件 / IDE / 模型 / 外部工具自备。用户痛点是「学了不会配、配了跑不起来」，准备层就是诚实交底。

2.0 · 准备变「默认就绪」

内模接入、平台侧供给增强后，用户体感从「我对照清单自备」转为「环境已就绪，直接开干」。架构上准备层仍可承载清单/依赖说明，口播可压成半句。

因此讲述公式建议用稳三拍 + 一字幕： 学金案 → 干出活 → 留下来；需要时加一句「1.0 中间多一步：对照准备清单」。 不要为了 2.0 提前删掉准备，否则 1.0 验收与样板间三层结构会对不上。

3. 「逛做交学」怎么用才不打架？

它适合解释双壳入口与任务中心，请当作主线的界面映射表，而不是第二套四字经：

价值主线 界面落点（逛做交学 · 仅对照） 用户一句话
学习 逛：找案例 / 样板间学习层 别人怎么做成的？
准备（1.0 加讲） 逛：样板间准备层 · 学习包 我要自备什么才能跑？
开干 逛→做：一键打样 / 做任务橱窗 → 计划确认与执行 别讲了，帮我出一版。
沉淀 交：预览与推送 · 并回到学：场景可复制复跑 结果留下，下周还能再来。

注意：这里的第二个「学」是「组织可复制」，对应主线里的沉淀，不要和主线开头的「学习」混成两个「学」字牌——口播请固定说「学习 / 开干 / 沉淀」，避免听众以为主线改名了。

4. 推荐讲述节奏（导入 → 岗位）

30 秒导入（进入三条旅程前）

「用户之旅主线只有一条：先学习金案方法，1.0 再对照准备清单，然后开干打样把活干完，最后沉淀——交付留下、入口可复跑。 找案例和做任务不是两条产品，是这条主线的两端；任务中心里的计划、交付、推送，都落在开干与沉淀里。 下面用商城、营销、服务三个岗位，把这条线走一遍。」

为何刷新上一版？

1

商城运营：从「只讲价监」升级为「评论英雄 + 价监旁证」

价监 ROI 好记，但是单点 Skill；亚太评论是现网唯二「专家团多步接力」之一（三段），最能证明「能力编排」不是空话。同属商城/电渠语境，听众不需要换脑。

2

营销经理：岗位名保留，案例从「泛橱窗」改为可点击金案

上一版口播易滑向「做任务里点营销 Agent」——偏抽象。现网更硬的是 MEA 卖点卡小语种初译与欧洲合规抽检，对应战役前真实闸口。

3

服务经理：原绑定正确，加深「口径源」叙事即可

电池过热客诉 SOP 金案完整，且直接回应「经验随人走」。无需换人，只需强调班组复跑与提精选回灌。

02三条具象化用户之旅

三条均按同一主线：学习 →（准备）→ 开干 → 沉淀。 「准备」在 1.0 Demo 如实走；面向 2.0 展望时可口播压成「环境就绪后进入开干」。人名虚构，金案取自现网。

03沉淀带走什么（不再另起「用得留回」）

闭环不必再喊第四套四字。走完主线后，只问一句： 「沉淀环节，他口袋里多了什么？」 答案固定三类，且都挂在沉淀上——依赖性由此产生，无需新口号。

一句话收束：学了会干、干了有产出、产出和下周入口都留在平台——这就是闭环。 「好打样提精选」是运营加厚，口播点到即可，不必升格成与主线并列的第四段旅程。

04备选角色与何时替换

若听众偏零售门店

用门店赋能经理 + Nova 陪练替换营销经理：现成 retail-training 两步接力（培训内容→陪练），差异点同样强。

若听众偏经营分析

用代表处运营 + MEA SO 周报替换营销经理：周度刚需极强，但编排演示弱于评论，适合「经营侧」专场。

不建议本轮主讲

HR 简历、纯知识库 RAG：金案在，但离「商城/营销/服务」决策语境远，易把讨论带偏。

1.0 边界别夸大

准备层仍是体外清单；依赖性建在「金案方法 + 任务复跑 + 货架精选」，不承诺本阶段代配全环境。

05汇报口播与 Demo 路径

开场 90 秒（主线导入 + 岗位，校准版）

「先定主线：用户之旅只有学习 → 准备 → 开干 → 沉淀这一条。1.0 准备要对照清单自备；2.0 内模进来后，准备会变薄，但学了再干、干完要留下，不变。 找案例和做任务是两端，不是两条产品。 下面三个岗位走同一条线——商城电渠用亚太评论三段接力看见编排；营销用 MEA 初译加欧洲合规过战役闸；服务用电池过热 SOP 统一口径。」

现场最短 Demo

  1. 业务用户登录 → 找案例 → 电渠评论 → 亚太金案 → 一键打样看三段接力（主）
  2. 口播闪过：价监「2天→4小时」（旁证）
  3. 如有时间：客诉金案打样 或 只打开 MEA/合规金案封面讲战役闸
