11 · 关键纠正

「配」不是工具调用层

✕ 易歧义理解

1配 = 平台工具货架，点了就能调
2「仅了解」= 永远不在平台执行
3配 = 平台已提供全部算力
4场景说明书 = 项目采购清单

✓ 正确产品语义

11.0：体外打样参照配置（自备）
2一键打样 = 平台内有限执行（另入口）
32.0：平台托管模型/服务，自备权重↓
4账本 A≠账本 B，分表汇报
讲不清「配」，2.0 预算一定会投错11 / 20
本页是纠正高潮，停顿让听众消化。
