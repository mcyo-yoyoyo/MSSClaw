# 首页 MAX 搜索融合版本（2026-11-04）

分支：release/max-integration-20261103
合入最新主分支：f2631f5。

## 本轮优化

- 首页搜索框与 MAX 合并：右上角机器人、左侧问候气泡、悬浮模式按钮。
- 使用指引放在首位，采用线性星星图标；标题保持原位居中，输入框加宽、机器人偏右，压缩纵向留白。
- 空输入使用轮播提示，聚焦/输入后停止；清空后继续保持输入焦点。
- 搜工具复用关键词检索与平台卡片，记录明确提交的检索；找方案、做洞察携带问题和模式进入真实对话，返回首页保留搜索现场。
- 首页不再重复展示右下角悬浮 MAX，其他业务页的入口保留。

## 主分支兼容

保留主分支的区域/领域资产过滤、多个超级管理员支持、卡片曝光上报调整及 MAX 登录限制。对话初始化合并保留登录草稿、首页问题、模式和返回来源；登录守卫仍在实际发送前执行。

## 构建与部署

合并后执行前后端构建；未运行自动化测试或浏览器验收。构建结果不代表完整用户流程验收。本次优化不增加数据库迁移。

不提交本地环境配置、日志、数据库备份或 .codex_tmp 临时诊断文件。

## 合并后交互修复（2026-11-04）

- MAX 登录草稿在组件外临时保存，登录时绑定到该账号；组件按身份重建后恢复问题、模式和首页来源，仅恢复输入，不自动发送。取消登录、退出或切换账号清理待恢复草稿。当前覆盖就地登录；OAuth 整页跳转仍不保留内存草稿。
- 首次发送（含首页自动发送）通过登录检查后清空输入；失败重试使用失败消息文本，不覆盖用户另写的草稿。
- 建议问题只缓存非空结果；空响应不覆盖已有建议，重新进入模式仍能使用本地兜底。
- 验证：前端构建、全量前端测试；ego lite 中使用模拟会话响应与身份切换验证草稿恢复、不自动发送、首发清空及空输入回车不重复提交。未执行真实密码登录或模型生成验收。

## 旧接口权限收口（2026-11-04）

- 旧 Agent、Skill、提示词、工作流、知识库和记忆管理接口统一要求登录及对应菜单权限；写操作另需编辑权限。旧 Agent / Skill 查询复用目录的区域、领域范围，Agent 人设修改也在数据库写入条件中校验范围。
- 执行列表仅返回当前登录人的记录，包含超级管理员；历史匿名记录不再通过此接口展示。运营聚合统计沿用原有专用接口。
- 执行流拒绝匿名与失效会话，执行身份只取服务端会话；登录和参数校验通过后才申请 SSE 并发名额。
- 前端旧中心查询、写入和执行历史请求补齐认证头。
- HTTP 回归覆盖匿名/失效会话、菜单只读/编辑权限、身份伪造、记录归属及跨组织修改拒绝；测试不修改业务数据或调用真实模型。
