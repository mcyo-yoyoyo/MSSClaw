# 资产分享链接与分享统计：需求记录

> 状态：需求已全部确认（2026-10-20），分两期实施：第 1 期独立详情页 + 分享按钮（实施中，分支 `feat/share-detail-pages`），第 2 期分享浏览统计 + 资产明细「案例」标签。
> 来源：2026-10-19 需求澄清会话；2026-10-20 资产拆表完成后按新库表重新规划。

## 目标

把 AI 工具（内部、外部）、案例、Skill、Agent 分享出去：生成分享链接，用户点开后进入资产详情页；后台资产明细统计分享带来的浏览。

## 实施方案

**第 1 期：独立详情页 + 分享按钮（只改前端，统计口径不动）**

- 路由 `#/detail?type=tool|skill|agent|case&id=<id>`；在应用外壳里渲染，隐藏平台顶部导航。
- 顶栏：← 返回（平台内进入回上一页；直达回该类列表）、平台 logo（回首页）、分享、登录（仅游客）。
- 状态：找不到 / 已下架 / 已删除 →「该内容已下架」+ 回列表；游客无权 →「登录后查看」+ 登录，登录后回到详情页；已登录无权 →「暂无权限查看」。可见范围复用货架的 `canViewAsset`。
- 平台内所有打开详情的入口改为当前页跳详情路由，去掉工具 / Skill / Agent 详情弹窗；案例也在当前页打开。
- 分享按钮复制「【MSS AI提效平台】标题｜一句话简介 + 链接」并提示已复制。
- 打开详情页照旧记 `detail` 事件；案例第 1 期仍不埋点。
- 以下仍用弹窗，不跳详情页：运营后台「配置 Skill / 配置 Agent / 配置工具」（带更新、下架等管理操作）；「我的提交」（要能看到自己未上架的资产，详情页会判成已下架）；AI 智库（对话只存在页面状态里，跳走再回来会丢）。
- 视图键沿用 `market-tool`（导航配置、权限、页面访问统计都按它记），只有地址换成 `#/detail`。

**第 2 期：分享浏览统计 + 案例标签**

- 「直达」：页面加载后渲染的第一个路由就是详情页，且导航类型为 `navigate`（刷新 `reload`、前进后退 `back_forward` 不算；OAuth 回跳先落在 `/oauth/callback`，自然不算）。直达时记 `detail_direct`（代替 `detail`），游客可记，不改表结构。
- 案例接入埋点：资产类型加 `case`，已发布且未删除的案例进入可统计内容白名单。
- 资产明细加「案例」标签；「详情浏览数」= detail + detail_direct，「分享浏览数」= detail_direct，两列只算区间；CSV 同步。

**不做**：分享人统计、分享按钮点击埋点、二维码 / 海报、提示词 / 快讯 / 办公场景、总览卡片、服务端按人过滤可见范围（货架的可见范围本就只在前端判断，详情页与之同级，不是安全边界；如需防外泄另行立项）。

## 代码现状（2026-10-19 调研）

- **路由**：hash 路由，解析在 `apps/web/src/domain/appRoute.ts`，只认 `chat`、`id` 参数；视图切换在 `features/AppViewRouter.tsx`。`main.tsx` 在加载时一次性判断 `/oauth/callback` 和 `#/case-insight?`，后者在应用外壳之外独立渲染（无登录态、无埋点）。
- **详情现状**：工具 `#/market-tool?id=` 可深链，但打开后 hash 被改写为货架页、id 丢失；Skill / Agent 详情是本地 state 弹窗（`MarketSkillDetailModal`、`CatalogAgentDetailModal`），无 URL；案例有独立页。
- **埋点**：`MarketEngagementEvent` 已有 contentId、assetType、action、dateKey、visitorHash、visitorType（user / guest）、幂等 eventId。assetType 目前只有 tool / skill / agent / office-scene，且 contentId 必须在目录中存在；案例未接入任何埋点。
- **资产明细**：`#/portal-dashboard` → `features/ops/PortalTrafficPanel.tsx`，标签：外部工具 / 内部工具 / Skill / Agent；列：名称、海外/国内、浏览数（detailPv）、收藏、点赞、点踩、跳转或下载；CSV 前端导出。行数据由 `portal-analytics.service.ts` 生成，现有计数把区间事件与历史累计用 `Math.max` 混合。
- **OAuth 回跳**：登录前把当前 hash 存 sessionStorage；服务端 `returnTo` 仅接受 `#/` 开头且 ≤ 200 字符。详情页链接需控制长度。
- **部署**：链接基于 `window.location.origin`；nginx `try_files … /index.html`；内网部署。
