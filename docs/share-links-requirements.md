# 资产分享链接与分享统计：需求记录

> 状态：需求已确认大部分，**暂缓实施**（2026-10-19）。先做资产拆表（见 [database-mysql-design.md](database-mysql-design.md) B 域），拆表完成后再回到本需求。
> 来源：2026-10-19 需求澄清会话。

## 目标

把 AI 工具（内部、外部）、案例、Skill、Agent 分享出去：生成分享链接，用户点开后进入资产详情页；后台资产明细统计分享带来的浏览。

## 已确认

| # | 问题 | 结论 |
|---|---|---|
| 1 | 打开链接是否要登录 | 跟平台现有游客规则走：游客现在能看的，链接也能看；使用、下载等仍要登录。分享链接**不额外放开权限**。通过链接打开详情时要补上可见范围（public / org / private）检查（现状：工具弹窗只校验 published，深链能绕过可见范围） |
| 2 | 统计粒度 | 只按资产统计，**不记录分享人** |
| 3 | 资产范围 | 内部工具、外部工具、案例、Skill、Agent 共 5 类。提示词、快讯新闻不做 |
| 4 | 分享按钮 | 只放在详情页。点击复制「【MSS AI提效平台】标题｜一句话简介 + 链接」并提示已复制。不做二维码、海报 |
| 5 | 失效链接 | 显示提示页 + 回到该类资产列表的按钮，不报错、不静默跳首页 |
| 6 | 分享链接形式 | 分享链接 = 详情页链接，不加任何标记。「直达」= 页面首次加载即落在详情页；平台内点击、刷新、前进后退、登录后跳回均不计。已知会混入书签、历史记录、新标签打开 |
| 7 | 详情形式 | 单独的详情页，不用弹窗 |
| 8 | 资产明细 | 增加「案例」标签页 |
| 9 | 工具下线 | 工具只有下架；下架后详情页显示「已下架」。新增资产时生成唯一 ID，之后不可修改 |
| 10 | 新列口径 | 只算所选时间范围，不与历史累计取较大值 |
| 11 | 明细列 | 分「详情浏览数」和「分享浏览数」两列 |
| 12 | 总览卡片 | 第一版不加汇总卡片，只在资产明细加列 |
| 13 | 平台内点击 | 也进单独详情页，去掉现有详情弹窗 |
| 14 | 详情页外壳 | 不带平台顶部导航 |
| 16 | 无权限 / 下架 | 已下架或删除 →「该内容已下架」；游客无权 →「登录后查看」+ 登录按钮，登录后回到详情页；已登录无权 →「暂无权限查看」 |
| 17 | 打开方式 | 平台内点击在当前标签页打开（详情页仍在应用内、只隐藏导航，登录态、登录拦截、埋点可用）。案例也改为当前页打开 |
| 18 | 详情页顶栏 | 只放：← 返回（平台内进入回上一页；直达则回该类列表）、平台 logo（回首页）、分享、登录（仅游客） |

## 待确认（下次从这里继续）

- **Q15 资产 ID**：取决于拆表方案。拆表后若有自增编号，分享链接可用编号；注意 Skill / Agent 的字符串 ID 在不同工作区会重复（如 `agent-marketing`），链接里单用字符串 ID 不唯一。
- **Q19 两列关系**（推荐）：现有「浏览数」改名「详情浏览数」，含分享进入；「分享浏览数」是其子集。分享按钮点击不埋点。
- **Q20 详情页内容**（推荐）：沿用现有弹窗的内容和操作，整页布局，不新增字段。
- **Q21 旧链接**（推荐）：`#/market-tool?id=…` 与 `#/case-insight?workspaceId=…&id=…` 继续有效，自动跳到新详情页。
- **Q22 办公场景**（推荐）：内部办公推荐里的办公场景卡片第一版不做。

## 代码现状（2026-10-19 调研）

- **路由**：hash 路由，解析在 `apps/web/src/domain/appRoute.ts`，只认 `chat`、`id` 参数；视图切换在 `features/AppViewRouter.tsx`。`main.tsx` 在加载时一次性判断 `/oauth/callback` 和 `#/case-insight?`，后者在应用外壳之外独立渲染（无登录态、无埋点）。
- **详情现状**：工具 `#/market-tool?id=` 可深链，但打开后 hash 被改写为货架页、id 丢失；Skill / Agent 详情是本地 state 弹窗（`MarketSkillDetailModal`、`CatalogAgentDetailModal`），无 URL；案例有独立页。
- **埋点**：`MarketEngagementEvent` 已有 contentId、assetType、action、dateKey、visitorHash、visitorType（user / guest）、幂等 eventId。assetType 目前只有 tool / skill / agent / office-scene，且 contentId 必须在目录中存在；案例未接入任何埋点。
- **资产明细**：`#/portal-dashboard` → `features/ops/PortalTrafficPanel.tsx`，标签：外部工具 / 内部工具 / Skill / Agent；列：名称、海外/国内、浏览数（detailPv）、收藏、点赞、点踩、跳转或下载；CSV 前端导出。行数据由 `portal-analytics.service.ts` 生成，现有计数把区间事件与历史累计用 `Math.max` 混合。
- **OAuth 回跳**：登录前把当前 hash 存 sessionStorage；服务端 `returnTo` 仅接受 `#/` 开头且 ≤ 200 字符。详情页链接需控制长度。
- **部署**：链接基于 `window.location.origin`；nginx `try_files … /index.html`；内网部署。
