Principles

设计原则：门禁 + 评分，推广复制优先

学
材料齐套，15 分钟可上手
推
跨职能/代表处可宣贯
复
换组织只换数据与权限
控
安全涉密一票否决

Skill 评什么

原子能力是否干净可编排：契约清晰、可单测、可挂载、可组合。

Agent 评什么

门面专家是否能稳定编排多 Skill，解决一类可复制业务问题。

与「能跑就上」的区别：可调用 ≠ 精选露出。先保证安全与质量，再决定是否进入 Hub 精选推荐。

Flow Detail

各阶段进入 / 退出条件

S0
立项预审≤2 工作日
进入：有场景假设与目标用户。退出：通过「值得做」清单，或驳回合并已有能力。
S1
材料齐套提交前完成
进入：草稿可运行。退出：中英命名、标签归属、使用须知、样例/案例、测试记录齐套。
S2
业务价值评审≈业务主管节点 · ≤3 日
进入：齐套申请已提交。退出：普适/高价值/高频达标，业务归属与使用范围确认。
S3
质量与安全≈MSS 质量与运营 · ≤5 日
进入：业务主管通过。退出：功能/缺陷/安全硬门禁通过，五维评分达标。
S4
灰度试运行3–10 天按风险档
进入：终审通过（可带条件）。退出：约定窗口无 P0/P1，反馈可闭环。
S5
正式上架与复盘上架当日 + 定期
进入：灰度达标。退出：Hub 露出策略生效；30/90 日健康度复盘决定是否保留精选。

Decision Gates

裁决阈值与集市动作

正式上架

无硬门禁失败，且总分 ≥75，且 D1≥18、D4≥16。
动作：可调用；可申请精选露出。

带条件上架

总分 65–74，或单项薄弱但可限期整改。
动作：可调用；默认不进精选；挂整改单。

仅内部试点

价值局部成立，普适性不足。
动作：不上 Hub 精选；限定部门/区域可见。

驳回

硬门禁失败，或总分 <65，或同质化冲突未处理。
动作：退回修改；记录原因码。

原因码：VALUE_LOW / HOMOGENEOUS / INCOMPLETE / QUALITY / SECURITY / META_POOR / OTHER

Next Steps

首期落地最小集 + 总结

立刻可做的 4 件事

1. 审批单挂五维评分卡与硬门禁勾选
2. 「可调用」与「精选露出」解耦决策
3. 同质化 ≥60% 提交时强制说明/合并
4. 安全门禁与 MSS 终审绑定（warn→block）

机制一句话

先流程图把关，再评分卡量化，硬门禁守底线，灰度与复盘保证集市长期「可学可推可复制」。
