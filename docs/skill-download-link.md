# Skill 下载链接

后台编辑 Skill 时，在基础信息「调用指令 / 版本」下方填写可选的「下载链接」（默认显示，无需展开高级项）。支持 HTTP/HTTPS（含内网地址），最长 2048 字符。保存会去除首尾空格，清空即恢复原包下载。

Skill 详情页主下载按钮保持原登录校验与下载计数：配置有效链接时在新标签页打开；未配置时优先下载上传的 Skill 包，无上传包则保留原有生成文件下载。历史版本列表仍下载该版本归档包，文件树不受影响。

数据库字段为 `skill.download_url`。部署需执行 Prisma migration deploy（`20261111040000_skill_download_url`）、生成 Prisma Client、构建并重启 API。旧数据为空，行为保持不变。批量 ZIP 的 Excel「其他配置JSON」支持保留该字段。

验证：API 保存/读取/清空/旧数据兼容和非法 URL 拒绝测试、前端 URL 选择测试、批量导入导出回归测试共 7 项通过；API 构建及前端类型检查通过。未进行浏览器端到端验收。
