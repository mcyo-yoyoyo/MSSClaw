# 页面返回按钮规范

页面或面板层级的返回操作使用 `components/common/BackButton`，通过 onClick 保留业务自己的返回目的地；不统一改为浏览器 history.back，避免分享落地页返回外站。

| 项目 | 规范 |
| --- | --- |
| 视觉 | 仅左向折线 SVG，不显示文字；19px 图标、1.7 描边 |
| 点击范围 | 桌面32×32px，粗指针设备40×40px；圆角8px |
| 状态 | 中性灰默认、浅灰绿悬停、按下轻移、键盘可见焦点、禁用无反馈 |
| 语义 | 必填 label，作为 title 和 aria-label，例如“返回对话” |
| 动效 | 系统要求减少动态时取消过渡和位移 |
| 不适用 | 取消表单、退出导览、日历翻页、轮播翻页和空状态主要操作 |

已统一智库主对话、独立方案、旧智库详情、资产详情、任务窄屏列表返回、任务返回入口和公告编辑页返回。现有业务跳转回调保持。
