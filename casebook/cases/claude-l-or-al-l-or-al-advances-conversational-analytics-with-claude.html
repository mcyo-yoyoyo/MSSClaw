欧莱雅利用 Claude 推进对话式数据分析

英文原题：L'Oréal advances conversational analytics with Claude
主领域 · 质量与运营关联 · GTM零售/电商 美妆消费品 数据分析 运营提效 提效 体验提升
核心观点

欧莱雅作为全球最大美妆公司，在内部 AI 平台部署 Claude 作为多智能体编排器，将自然语言问题转化为数据洞察和可视化。员工无需为每个临时问题构建自定义仪表盘，可直接用自然语言查询数据。该方案在对话式分析应用中达到 99.9% 准确率，相比此前生成式 AI 方法的 90% 大幅提升。平台月活用户达 44,000 人，日活 15,000 人，每月产生 250 万条消息。Claude 通过协调语义 API、数据检索、计算、产品主数据和地理主数据等 15+ 专用智能体，确保高精度和可靠性，推动欧莱雅向 Beauty Tech 领导者迈进。

AI 怎么落地

欧莱雅在内部 AI 平台中部署 Claude 作为核心编排器，接入其 Beauty Tech Data Platform，并管理用户身份和访问控制。当员工用自然语言提问时，Claude 首先解析问题意图，然后动态路由到多个专用智能体：语义 API 智能体负责理解查询语义，数据检索系统从数据平台获取相关数据，计算智能体处理数学运算，产品主数据智能体和地理主数据智能体分别提供产品和地理维度信息。Claude 协调这些智能体的工作，并将结果综合为清晰的答案和配套数据可视化。系统通过将特定类型查询路由到专用智能体来降低幻觉风险，例如计算任务交给计算器智能体，产品维度查询交给产品主数据智能体。人工审核环节体现在系统设计中对准确性的持续跟踪和缓解措施，以及通过 LLM 作为评判者的自动评估来验证模型性能。该架构支持 15+ 专用智能体，覆盖对话式分析、软件开发生命周期等场景，其中 Claude Code 在 30-50 名开发者中早期测试。

带来什么价值

效率提升：员工无需为每个临时问题构建自定义仪表盘，可直接用自然语言查询数据，大幅缩短获取洞察的时间。准确性提升：对话式分析应用准确率从 90% 提升至 99.9%，增强了员工对 AI 能力的信任，促进大规模采用。成本节约：通过自动化重复性任务，员工可专注于更高价值工作，间接降低人力成本。收入增长：原文提到加速上市时间、获得市场份额和加快配方研究，但未提供具体数字。体验提升：员工数据查询体验从依赖技术团队构建仪表盘转变为自助式自然语言交互，显著改善用户体验。

可借鉴点

欧莱雅的实践表明，对于复杂分析任务，采用多智能体编排架构比单一模型更有效。中国企业可借鉴：1) 将自然语言查询分解为语义理解、数据检索、计算、主数据等专用智能体，由核心模型编排，可显著提升准确率（从 90% 到 99.9%）。2) 通过路由特定查询到专用智能体来降低幻觉风险，例如计算任务交给计算器智能体，产品维度查询交给产品主数据智能体。3) 在内部 AI 平台中集成身份和访问控制，确保数据安全。4) 采用 LLM 作为评判者的自动评估机制，持续验证模型性能，为模型选型提供依据。5) 从对话式分析切入，逐步扩展到软件开发生命周期，实现渐进式 AI 采用。

1

公司背景与 AI 战略

欧莱雅是全球最大的化妆品和美容公司，在 150 多个国家运营，拥有 37+ 国际品牌，涵盖护肤、护发、彩妆和香水。公司定位为 Beauty Tech 领导者，将前沿研究与 AI、数据和数字能力相结合。2023 年开始生成式 AI 之旅，目标是在全球员工中普及 AI 能力，同时保持安全、治理和业务价值。

2

核心挑战：对话式分析

欧莱雅需要复杂的推理能力来处理涉及数学、编码和 SQL 生成的复杂分析和财务任务，特别是对话式分析，员工可以用自然语言提问并获得准确洞察。此前，员工需要为每个临时问题构建自定义仪表盘，效率低下。公司还寻求通过消除重复性任务来提高生产力，加速上市时间，获得市场份额，并加快配方研究。

3

选择 Claude 的原因

欧莱雅通过严格测试选择了 Claude。其自动评估能力（如 LLM 作为评判者）多次证明 Claude 模型在各种用例中的优越性，尤其是最复杂的用例。对于对话式分析，欧莱雅进行了广泛的手动测试，验证了 Claude 的高级推理能力对于要求准确性和可靠性的应用至关重要。

4

多智能体编排架构

欧莱雅以两种主要方式使用 Claude：在需要高质量推理能力的 AI 助手中，以及通过 GitHub Copilot 和 Claude Code 在软件开发生命周期中。对于对话式分析，Claude 作为多个专用智能体的主编排器，将用户问题转化为洞察和可视化。当员工提问时，Claude 协调语义 API 智能体、数据检索系统、计算智能体、产品主数据智能体和地理主数据智能体。Claude 根据用户问题决定调用哪些专用智能体，协调它们的工作，并将结果综合为清晰的答案和配套数据可视化。

5

降低幻觉风险

架构有助于缓解潜在的准确性问题。通过将特定类型的查询路由到专用智能体，系统在多样化的分析任务中保持高准确率，同时 Claude 管理整体工作流并综合结果。系统以自然语言查询欧莱雅的 Beauty Tech Data Platform，同时管理用户身份和访问控制。测试验证了架构的有效性：Claude 3.7、4 和 4.5 Sonnet 在驱动子智能体满足用户需求方面是最有能力和最先进的模型。
