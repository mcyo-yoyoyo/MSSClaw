Shopify 如何利用 Google Cloud 上的 Anthropic Claude 强化 Sidekick

英文原题：How Shopify uses Anthropic’s Claude on Google Cloud to supercharge Sidekick
主领域 · 电商关联 · GTM关联 · 质量与运营零售/电商 企业SaaS 电商 数据分析 运营提效 提效 增收 体验提升
核心观点

Shopify 为服务数百万商家，推出 AI 商务助手 Sidekick。Sidekick 基于 Anthropic Claude 模型（现用 Claude Sonnet 4.5）并部署在 Google Cloud 上，通过自然语言对话为商家提供个性化支持。它能将自然语言转化为复杂的 ShopifyQL 分析查询，指导新商家从店铺搭建到首次销售，并执行多步骤推理。Claude 的先进推理能力与 Google Cloud 基础设施结合，确保 24/7 可用性和亚秒级响应。结果：复杂数据分析从需要技术培训变为自然对话即可完成，新创业者实现首次销售的时间从数周缩短至数天。此外，Shopify 内部使用 Claude Code 构建工具，效率大幅提升。

AI 怎么落地

Sidekick 是 Shopify 的 AI 商务助手，集成在商家仪表盘中。它接入 Shopify 平台数据，包括产品信息、分析数据、业务上下文和 ShopifyQL 查询语言。工作流程：商家用自然语言提问，Sidekick 调用 Claude Sonnet 4.5 进行推理，将问题转化为 ShopifyQL 查询，并可能执行多个工具调用（并行或顺序）以获取相关数据，然后综合生成回答。触发方式为商家在对话界面主动提问。模型分工：Claude 负责自然语言理解、推理和查询生成；Shopify 内部系统执行查询并返回数据。人工审核：对于分析查询，系统自动执行，但商家可查看结果并进一步追问；对于指导性建议，Sidekick 提供内容，商家自行决策。此外，Shopify 内部使用 Claude Code 构建工具，员工（包括非开发者）可通过自然语言描述快速生成应用，无需人工编码审核。

带来什么价值

效率提升：复杂数据分析从需要学习 ShopifyQL 变为自然语言对话，节省商家时间；内部工具构建从数天缩短至数分钟。成本降低：原文未提供具体成本数字，但通过自动化分析和支持，减少了对人工专家的依赖。收入增长：新创业者实现首次销售的时间从数周缩短至数天，可能加速收入产生。体验提升：商家获得 24/7 个性化支持，感觉像“联合创始人”或“生命线”，帮助小企业“脱颖而出”。

可借鉴点

中国零售或跨国企业可借鉴：1. 将复杂查询语言抽象为自然语言界面，降低数据使用门槛，让非技术用户也能进行深度分析。2. 采用“模型+云基础设施”组合，确保 AI 助手的高可用性和低延迟，这对实时对话体验至关重要。3. 内部推广 AI 编码工具（如 Claude Code），让非开发人员也能构建工具，加速内部创新。4. 将 AI 助手定位为“联合创始人”而非简单客服，提供端到端业务指导，增强用户粘性。

1

Shopify 与 Sidekick 简介

Shopify 为全球数百万企业提供电商平台，从首次创业者到企业品牌。他们构建了 Sidekick，一个 AI 商务助手，旨在帮助各种规模的商家更快完成更多工作。Sidekick 利用全面的 Shopify 知识、上下文和数据，通过对话式 AI 提供高度个性化的支持，并具备高级推理能力，提供专家级商业指导。

2

Claude 在 Google Cloud 上的应用

Claude 的高级推理能力与 Google Cloud 的基础设施相结合，确保商家全天候获得专家级指导。Google Cloud 托管多个 Anthropic 模型，保证 Sidekick 24/7 可用。该组合提供复杂的多步骤分析，同时保持亚秒级响应时间，这对自然对话至关重要。Shopify 应用 AI 总监 Andrew McNamara 表示：“推理能力很棒，延迟与质量的权衡对我们来说是完美的甜蜜点。”

3

商家支持挑战

Shopify 服务的商家背景各异：有些需要从基础设置开始的指导，有些则需要运行复杂分析查询，这通常需要深入了解 Shopify 的查询语言 ShopifyQL。McNamara 解释说：“很多商家必须真正学习如何使用 ShopifyQL 并深入研究才能获得所需洞察。”这造成了商家与数据驱动决策之间的巨大障碍。

4

Sidekick 如何利用 Claude

Sidekick 充当始终可用的合作伙伴：将自然语言翻译成复杂的 ShopifyQL 分析查询，结合多个数据源获取上下文洞察；指导新商家从店铺设置到 SEO 优化再到首次销售；提供复杂的多步骤推理，整合产品信息、分析和业务上下文；在每次交互中执行多个工具调用以保持对话质量；在不牺牲响应质量的情况下将专业知识扩展到数百万商家。

5

Sidekick 赋能商家

当商家登录仪表盘时，他们发现了一个了解其业务的合作伙伴。McNamara 将 Sidekick 描述为商家可以依靠的“联合创始人”，尤其对只有一名员工的小商店很有价值。Sidekick 现在利用 Claude Sonnet 4.5 来编排通常需要技术专长的复杂推理链。商家现在只需询问 Sidekick，它就能结合 Shopify 的其他方面——查找特定产品、编写分析查询，然后利用这些信息编写更好或更符合上下文的查询。这种代理循环不断引入相关上下文以制定完美响应。

6

Shopify 内部使用 Claude Code

在 Sidekick 改变商家体验的同时，Claude Code 是塑造 Shopify 员工构建和部署内部工具的关键驱动力。整个组织都接受了反射性 AI 使用，工程师和非工程师都能在几分钟内创建复杂的应用程序，而不是几天。McNamara 说：“Claude Code 改变了我们在 Shopify 构建内部工具的方式。它在公司内部被广泛使用，因为它直接与我们的平台集成，用于搭建工具。速度太疯狂了——我现在可以更快地构建东西。”这种集成帮助民主化了工具创建——非前端开发人员的员工现在可以构建以前需要专业知识的专业界面和工作流。
